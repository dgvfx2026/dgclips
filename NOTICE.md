# DGCLIPS — procedência

DGCLIPS é uma adaptação de interface e implantação do SupoClip.

- Original: https://github.com/FujiwaraChoki/supoclip
- Revisão base: `6c700f38697091f678754e79c651c5d3ba696c93`
- Licença original mantida: GNU Affero General Public License v3.0, em `LICENSE`.
- Alterações desta distribuição: identidade DGCLIPS, estúdio em português, biblioteca, estilos, demonstração, configuração Vercel e configuração de processamento de produção.

O motor original e seus avisos de autoria foram preservados. O README original está em `docs/UPSTREAM_README.md`. Publique o código desta versão no seu repositório e configure `NEXT_PUBLIC_SOURCE_URL` para disponibilizá-lo na interface.
